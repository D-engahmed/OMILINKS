# OmniLinks Glossary

Organization / Tenant
The contracting organization and primary security boundary.

Client Account
An external business served by a service-provider tenant.

Program
An operational engagement for a client.

Sector
A functional operating area.

Team
An execution unit within a sector.

Workforce Member
The normalized operational concept for a human or AI worker.

Human Agent
A human worker handling customer operations.

AI Agent
A governed AI worker configuration and runtime policy.

Customer
An external person interacting with the organization.

Channel Identity
A provider-specific identity belonging to a customer.

Conversation
A unified operational interaction.

Channel Connection
Tenant-owned configuration connecting OmniLinks to a communication provider.

Action
A business capability that can be executed by a human, AI or workflow.

Approval
Explicit authorization required before a designated action executes.

Workflow
A versioned deterministic automation.

Knowledge Base
A tenant-scoped collection of authorized knowledge.

AI Run
One execution of an AI agent.

Entitlement
A backend capability decision for the current commercial state.

Usage Record
An immutable measurement of consumption.

Outbox Event
A transactionally persisted event awaiting reliable dispatch.

Audit Event
Security/business evidence for a significant operation.

Platform Plane
Internal OmniLinks operations and platform controls.

Tenant Plane
Customer organization operations.

Customer Plane
External end-customer interaction.

Containment
A configured operational measure of a conversation resolved without human takeover.
